# Second Life — LSL Scripts

Open source LSL code snippets for Second Life:

- **[WalkToMe.lsl](WalkToMe.lsl)** — Proof of concept for the Corrade bot: automates a scripted agent from a single script. Drop your edited Corrade configuration into an object and click it to make the bot walk towards it. Attach the object as a HUD to have the bot follow you.

- **[animeshcycle.lsl](animeshcycle.lsl)** — A scripting exercise in reducing bytecode: cycles an animesh object through all of its animations.

- **[sniffy.lsl](sniffy.lsl)** — Listens on a channel for any message that passes by. Define the channel in a text dialog — ideal for debugging.

## Usage

Copy a script into an object's contents in-world (**Build → Edit → Contents → New Script**), adjust the configuration values at the top, and save.
